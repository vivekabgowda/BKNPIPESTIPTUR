One-time Firebase setup. After this, data works on MacBook + Android together.

1Create Firebase project

Go to console.firebase.google.com → Add project → Name hume-pipes → Create

2Add Web App & copy config

Click </> icon → Register → Copy the firebaseConfig { ... } object

3Enable Firestore

Build → Firestore Database → Create database → Test mode → Location: asia-south1 → Enable

⚠Secure your data (important!)

Test mode allows anyone with your config to read/write your data. After setup, go to Firestore → Rules and replace the rules with:
rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /{doc=**} { allow read, write: if request.auth != null; } } }

4Enable Authentication

Build → Authentication → Get started → Email/Password → Enable → Add your email & password under Users tab

5Paste config

Config saved in browser. Only needed once per device.
